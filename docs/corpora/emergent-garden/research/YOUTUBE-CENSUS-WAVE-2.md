## Alternative explanations and failure modes

1. Playlist count can differ from the channel statistics count because deleted, private, upcoming, live, or recently indexed records may not resolve identically.
2. `contentDetails.caption` is a coarse availability signal, not proof that a legally retrievable transcript exists for this campaign.
3. A URL in a creator description establishes a direct outbound edge, not endorsement of every claim at the target and not proof of repository lineage.
4. An Atom-feed row set can be internally correct while still being an incomplete channel census.
5. Missing links may reflect description edits, shortened URLs, client-rendered content, or provider-field limitations rather than true absence.
