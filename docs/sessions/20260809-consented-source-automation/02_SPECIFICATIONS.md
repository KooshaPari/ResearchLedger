# Specifications

An import requires an active consent record matching provider, purpose, data category,
acquisition method, and URL scope. LinkedIn is approved-API capability probe followed by
official export/permalink/manual content only. GitHub is Rust-owned `gh` credential first,
first-party Device Flow fallback, then explicitly labelled advanced manual import.

Every claim must retain artifact ID, offsets, excerpt hash, and acquisition/consent provenance.
URL handling defaults to exact canonical URLs; reference crawl is explicitly bounded and
reviewable. See the canonical design for the complete contract and acceptance list.
